# Motion-generator Aesly
HTML/GSAP-animaties (Poppins, indigo-koraal gradient) naar mp4 (1080x1920, 30 fps) en carrousel-PNG's.
Gebruik: `npm i`, content in een JS-bestand (zie content1.js), `node build.js ./content1.js <uitmap>`, daarna integrate.py om bestanden en planning bij te werken.
Let op: paden in de scripts verwijzen naar /tmp/gen en /home/claude/aesly-media; pas aan indien nodig.
